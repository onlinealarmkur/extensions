# Browser Extensions of Online Alarm Kur

Alarm clock and countdown timer that live on your browser toolbar. Set one-time or repeating alarms and start countdown timers without opening a website; they keep running in the background even with the popup closed.

> This repository is for **bug reports and feedback only**.

## Install

- Chrome: https://chromewebstore.google.com/detail/online-alarm-kur-alarm-cl/nkpilooehebijefccjlonbfmpiefimog
- Edge: https://microsoftedge.microsoft.com/addons/detail/online-alarm-kur-alarm-c/nhajicldjnmlopjimbnhenablbopfbak
- Opera: https://addons.opera.com/en/extensions/details/online-alarm-kur-alarm-clock-timer/
- Firefox: https://addons.mozilla.org/en-US/firefox/addon/online-alarm-kur/

## What it does

- **Alarms:** one-time or repeating (weekdays or every day), each with an optional label.
- **Timer:** quick presets or a custom hours / minutes / seconds entry, with the remaining time shown on the toolbar badge.

## Report a bug

Open an issue in this repository's **Issues** tab.

To help a fix land quickly, please include:

1. **Browser and version** (for example Chrome 151), and your operating system.
2. **Extension version** (shown at the bottom of the popup).
3. **Steps to reproduce**, one action per line.
4. **What you expected** vs **what actually happened**.
5. **Whether the browser was open** at the time, or you noticed it only after reopening (this matters for alarm and timer timing).
6. A **screenshot** if the problem is visual.

## Feature requests

Ideas are welcome as issues. However, please note that the point of this extension is simplicity. Complex requests like account sync will most likely be declined, so the app stays small and focused.

## Privacy

Your alarms, timers, and settings are stored locally in your browser: https://onlinealarmkur.com/privacy/en/
