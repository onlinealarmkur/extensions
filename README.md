# Online Alarm Kur: Alarm Clock & Timer

An alarm clock and countdown timer on your browser toolbar. Set one-time or repeating alarms and start timers without opening a website. They keep running in the background when the popup is closed.

> [!NOTE]
> This repository is for **bug reports and feedback only**. The extension's source code is not published here.

## Features

- **Alarms:** one-time, weekdays, or every day, each with an optional label. Turn an alarm on or off without deleting it.
- **Timer:** quick-start presets or a custom hours / minutes / seconds entry. The remaining time shows on the toolbar badge.
- **Sounds:** Bell, Singing Bowl, Chime, Digital Beep, and Two-Tone Alarm, with a preview button and a volume control.
- **Snooze:** set the snooze duration in Settings, or turn snooze off.
- **Missed alarms:** if an alarm or timer goes off while nobody answers it, or while the browser is closed, you see it when you come back (within 24 hours). It does not ring late.
- **Settings:** light, dark, or system theme; desktop notifications on or off; toolbar countdown on or off.
- **32 languages,** with right-to-left layout for Arabic and Hebrew.

## Good to know

- An alarm can only ring while the browser is running. If the browser is closed at the alarm time, the alarm shows as missed when you open the browser again.
- A ringing alarm stops automatically after 60 seconds.
- The shortest timer is 30 seconds. This is a browser limit.
- Make sure that your operating system lets the browser show notifications. Otherwise you hear the alarm but do not see the alert.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml). The form asks for:

1. **Browser and version** (for example Chrome 151) and your operating system.
2. **Extension version** (at the bottom of the popup).
3. **Steps to reproduce**, one action per line.
4. **What you expected** and **what actually happened**.
5. **Whether the browser was open** at the time. This is important for alarm and timer timing.
6. A **screenshot**, if the problem is visual.

Before you open a new issue, please [search the existing issues](../../issues?q=is%3Aissue).

The extension stores your alarms, timers, and settings only in your browser. It does not collect data. Read the [privacy policy](https://onlinealarmkur.com/privacy/en/).
